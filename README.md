# SAReminder
![License](https://img.shields.io/badge/License-Personal%20Use%20Only-red)

Offline tasks, reminders, Jalali/Gregorian calendar, Pomodoro, habits and notes. Python + PySide6 + SQLite.
(c) Sadroddin Aghaei. All Rights Reserved.

Run: `pip install -r requirements.txt && python app.py`
Shortcuts (when the app is focused): Ctrl+N new task, Ctrl+F search, Ctrl+1..7 pages.
Release: `git tag v2.0.0 && git push origin v2.0.0` builds Windows x64/ARM64 (zip) and macOS Intel/Apple Silicon (dmg) into a draft release. Builds are unsigned.
Data: `~/.sareminder/sareminder.db`
